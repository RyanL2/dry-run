### Task 1: File-size-limit hit → `resource_limit` (M12)

A child killed by SIGXFSZ is invisible when it isn't the last command: `bash -c 'head -c 2G /dev/zero > big; true'`
exits 0. So detect the limit from the effect itself: any written file whose size reached
`file_size_max`. Keep the exit-code check (153 or −25) as well.

**Files:** Modify `src/dryrun/sandbox/spawn.py` (the kill classification after `proc.returncode`),
`src/dryrun/effects/record.py:compute_flags`, `src/dryrun/pipeline.py` (pass the limit),
`tests/unit/test_record.py` and `tests/sandbox/test_spawn.py`

### Task 2: Serialise commit recovery with apply; fsync the done marker

`recover_all` runs at daemon start and from `dryrun recover`. Neither takes a lock that `apply_run`
also holds. A daemon restart during a long apply could replay a live journal. `_marker_writer`
appends without fsync, so after a power loss a completed op can look pending, and recovery then
validates it against a fingerprint that has already changed.

**Files:** Modify `src/dryrun/commit.py` (`apply_run`, `recover_all`, `_marker_writer`) and
`tests/unit/test_commit.py`

- [ ] **Step 1: Failing test**

```python
def test_recover_waits_for_an_apply_in_progress(tmp_path):
    store = Store(tmp_path / "state")
    with store.commit_lock():                       # held by apply_run for its whole duration
        t = threading.Thread(target=recover_all, args=(store,))
        t.start()
        t.join(0.3)
        assert t.is_alive()                          # blocked, not replaying
    t.join(5)
    assert not t.is_alive()
```

- [ ] **Step 2: fail. Step 3: implement.**
  - `Store.commit_lock()` is `return self._locked(self.journal_dir / ".lock")`. It reuses the existing
    flock helper at `store.py:98`.
  - Wrap the body of `apply_run`, from `apply_changeset` to `finish`, in `with store.commit_lock():`,
    and do the same for the loop in `recover_all`.
  - In `_marker_writer.done`: add `f.flush(); os.fsync(f.fileno())` after the write.
- [ ] **Step 4: full suite. Step 5: commit** `fix: serialise commit recovery with apply; fsync done markers`
