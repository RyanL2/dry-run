Hypothesis: For short commands, fixed pipeline costs rather than overlay I/O decide the ratio.
Change: Per-stage timing (triage, fingerprint, git status, spawn, run, diff, judge) over 30 realistic short commands on a 20k-file repo.
Prediction: Fixed stages make up > 50% of added latency for commands < 1 s; fingerprint and git status are the largest.
Disproof: The run stage (overlay I/O) makes up > 50% of added latency for commands < 1 s.
