# C-0002 · overlay copy-up of large files · track: sandbox-perf · method: M-overhead-diagnosis · status: queued (sub-project 1)
Observation: The worst-case write-heavy workload runs at 1.65× native; a 1-byte append to a 1 GiB file costs 1.9 s of copy-up (measured 2026-09-22).
Hypothesis: Copying up large pre-existing files before modifying them dominates, so overhead grows with the bytes of pre-existing files modified.
Change: The same 2×2 microbenchmark as C-0001, reading the bytes axis.
Prediction: Overhead ratio rises with bytes of modified pre-existing files; it barely moves with file count.
Disproof: The ratio is flat across bytes (within 0.05×).
Budget: shared with C-0001.
Verdict: not yet run (shared run with C-0001; stopped by host memory pressure, 2026-09-23).
